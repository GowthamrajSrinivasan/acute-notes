## Rules

1. Edit only the files you own. Need a change elsewhere? Add a request below; the owner makes it.
2. New files over edits.
3. Test only your own files while working: `npx vitest run <your paths>`. Only the integrator runs the full suite.
4. Typecheck the whole project (`npx tsc --noEmit`) but judge only errors in your own paths.
5. Lint your own files: `npx eslint <your paths>`.
6. No local e2e except the integrator. No AI runs, live tests or recordings without the user's approval in that turn.
7. No commits, no `git stash`, `checkout`, `reset` or `restore` (sessions share one working tree; to see a test fail without your fix, revert your own edit by hand). No new dependencies. Only the integrator updates the plan's status and the memory notes.
8. `preserve` behaviour must not change. Nothing in a lane is wired into the pipeline; the integrator does that.
