# Cache service

## Reads

Results are served from the cache only when the cache holds a valid result.
A miss falls through to the primary database and fills the cache.
Check the logs carefully.

## Writes

Writes go to the primary database first, then invalidate the cache entry.
The cache invalidation is retried with exponential backoff up to three times before an alert fires.
Check the logs carefully.

## Limits

The cache must not exceed 2 GB per node.
Entries expire after ten minutes without a read.

## Operations

Deploys drain one cache node at a time behind the load balancer.
Check the logs carefully.
